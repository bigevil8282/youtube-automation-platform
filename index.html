TubeUp 기능 구조

키워드 발굴부터 AI 영상 생성까지 한 번에 실행하는 작업 흐름입니다.

1. 키워드 검색엔진
국가, 기간, 포맷을 조합해 떡상 후보를 자동 필터링합니다.
2. 트렌드 키워드
AI 자동화, 제목 공식, 쇼핑템, 무인매장
3. 글로벌 쇼핑템
알리/아마존형 제품 리뷰 주제를 쇼핑 영상 후보로 분류합니다.
4. 마이페이지 저장
분석할 영상을 저장하고 제작 대기 리스트로 보냅니다.
5. API Key Wallet
YouTube, Gemini, Grok API 사용량과 연결 상태를 확인합니다.
6. AI 영상 생성
제목, 썸네일, 대본, 프롬프트, 자막, CapCut 브리프를 생성합니다.
